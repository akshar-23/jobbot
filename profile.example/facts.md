# Jamie Example — facts for drafting (EXAMPLE PROFILE: not a real person)

This is the only source Claude may use when writing cover letters and answers to
application questions. If a question needs a fact that isn't here, don't guess:

## Rules for anything written from these facts

- Never invent a skill, credit, metric, title, date or result. Light rephrasing to
  match a posting is fine; new claims are not.
- If the job asks for something Jamie lacks (e.g. 3+ years in feature film, Houdini),
  don't claim it. Mention an adjacent skill only if it's genuinely adjacent.
- Studio work under NDA: say "an unannounced animated series" and never name the show.
- Style: plain words, specific details, varied verbs, no buzzwords ("passionate",
  "leverage", "synergy"). No "I am writing to apply". It should read like Jamie wrote it.
- Point to the demo reel for anything visual instead of describing it at length.

### Cover letters
Plain text, 4 short paragraphs, 200 words max, no greeting line:
1. 2–3 sentences: a specific reason this studio or role interests Jamie, tied to
   something concrete (a show, film, game or team named in the posting).
2. 3–4 sentences: the strongest matching credit, with specifics.
3. 2–3 sentences: a second strength that covers what paragraph 2 doesn't.
4. 2 sentences: interest in the role, the reel link, an invitation to talk.

### Short answers ("Why this studio?", "Tell us about a shot you're proud of")
2–5 sentences unless the form sets a length. Same rules.
